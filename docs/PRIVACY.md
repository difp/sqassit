# Приватность и персональные данные

Сервис хранит минимум данных, необходимых для записи на тренировки:

| Данные | Где | Зачем |
|---|---|---|
| `telegram_id`, username, first_name | `users` | идентификация игрока и отображение в расписании |
| `phone` | `users` | связь тренера с игроком и модерация; виден только тренеру в боте |
| `about` | `users` | «о себе» для тренера |
| `display_mode` | `users` | имя/фото или вымышленное животное |
| `show_username` | `users` | согласие показывать username |
| `notifications_enabled`, `notify_matches`, `notify_trainings`, `notify_messages` | `users` | выбор уведомлений: всё, матчи, тренировки, сообщения |
| `avatar_file_id` | `users` | аватарка через прокси Telegram (файл не сохраняется на диск) |
| заметки тренера | `users.notes` | CRM клуба |
| записи на тренировки | `bookings` | расписание, лист ожидания, посещаемость |
| переписка игрок ↔ тренер | `messages` | чат в приложении и уведомление в боте |
| соавторы мероприятий | `event_coauthors` | делегирование подтверждения заявок |
| обратная связь: проблема/предложение | `feedback` | доставка и ответ через бота |
| заявка в тренеры | `coach_applications` | рассмотрение заявки |
| матчи и их участники | `matches`, `match_players` | организация игровых встреч |
| ID сообщений-уведомлений | `event_notifications` | редактирование одного сообщения вместо ленты |

## Показ в расписании и чатах

- По умолчанию видны имя и фото из Telegram.
- В режиме «животное» имя и фото скрыты от других игроков **и от тренера**:
  в списках участников, CRM и сообщениях бота используется стабильное
  вымышленное животное.
- Username не отдаётся другим игрокам. Тренер видит его в боте для модерации;
  согласие «Показывать @username» управляет публичным показом в приложении.
- Телефон игрок указывает сам — вручную в профиле или кнопкой «Поделиться
  телефоном» в боте. Телефон виден только тренеру в боте.
- Telegram ID не выводится в сообщениях бота; он используется только внутри
  приложения для доставки ответов.
- Фото запрашивается через бота и кэшируется в памяти; на диск не сохраняется.
  Публичная ссылка на фото перестаёт работать в режиме «животное».

## Уведомления

- Общий переключатель отключает уведомления о матчах, тренировках и личных сообщениях.
- Тематические переключатели позволяют отдельно оставить матчи, тренировки или
  личные сообщения.
- Настройки доступны в «Настройки профиля» на вкладке тренировок и в профиле
  тренера; они не влияют на возможность открыть приложение или прочитать данные.
- Ответы на заявки в тренеры и служебные сообщения о роли не отключаются.

## Экспорт

`GET /api/me/export` (заголовок `X-Init-Data`) возвращает профиль, телефон,
записи на тренировки, отправленные сообщения, обращения через форму обратной
связи и заявку текущего пользователя.

## Удаление

`DELETE /api/me?confirm=true`:

- отменяет активные записи (лист ожидания продвигается по FIFO);
- удаляет сообщения, обратную связь, заявку и карточку пользователя;
- чистит кэш аватарки.

Ограничения:

- тренер/администратор не может удалить аккаунт, пока не снимет роль и не передаст
  занятия — иначе сломается владение расписанием;
- записи на тренировки удаляются вместе с профилем; счётчики занятых мест при
  этом остаются корректными (активные записи сначала отменяются).

После удаления пользователь может снова открыть Web App — будет создана новая
пустая карточка (это осознанный выбор: приложение не блокирует Telegram-аккаунт).
